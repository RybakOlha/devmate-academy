# OR Learning Lab by Olha Rybak

Статичний навчальний сайт: 5 курсів, каталог DevMate із 14 лабораторій, повноцінна LAB 01.

## Публікація в GitHub Pages
1. Розпакуйте ZIP.
2. Відкрийте GitHub-репозиторій `RybakOlha/devmate-academy` → **Add file → Upload files**.
3. Завантажте **вміст** папки `OR_Learning_Lab` (не саму папку й не ZIP). Підтвердьте Commit changes.
4. У **Settings → Pages** залиште `main` і `/(root)`.
5. Адреса після публікації: `https://rybakolha.github.io/devmate-academy/`.

## Перевірка
- Головна: `index.html`
- DevMate: `courses/devmate/index.html`
- Перша лабораторія: `courses/devmate/lab-01/index.html`
- Автотести LAB 01 використовують Web Worker, тож сайт потрібно відкривати через HTTP(S), наприклад GitHub Pages.
- Чернетки зберігаються лише в браузері. Результати не надсилаються автоматично в Moodle.

## Обмеження
Курси 1–3 і 5 наразі мають сторінки-заготовки. У DevMate повністю реалізована лише LAB 01; решта — анонси. Виконання довільного JS у Worker не є повноцінною пісочницею безпеки. Не вставляйте приватні ключі або дані учнів.

## Оновлення навігації та семантики
- З головного меню всіх сторінок прибрано пункт «Лабораторії»; лабораторії доступні лише через курс DevMate.
- З головного банера прибрано кнопку «Спробувати лабораторію»; залишено «Обрати курс».
- Додано перехід до основного вмісту з клавіатури, доступні назви секцій, активний пункт навігації та помітний фокус.
- Рекомендації щодо серверної частини наведено в `BACKEND_PROPOSAL.md`. Бекенд не встановлювався.
