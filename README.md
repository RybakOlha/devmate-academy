# DevMate Academy — виправлена навігація LAB 01

**Виправлено:** посилання на першу лабораторію тепер ведуть безпосередньо до `lessons/lesson-01/index.html`, а не до папки. Це усуває сторінку зі списком файлів при локальному перегляді.

**Важливо:** щоб працювали тести JavaScript у Web Worker, відкривайте сайт через локальний HTTP-сервер або GitHub Pages. При відкритті подвійним клацанням (адреса `file:///...`) оформлення та переходи можуть працювати, але автоматичні тести можуть блокуватися браузером.

## Найпростіший локальний запуск у Windows

1. Розпакуйте архів.
2. Відкрийте папку `devmate-academy` у Провіднику.
3. У рядку адреси Провідника введіть `cmd` та натисніть Enter.
4. У командному рядку виконайте `py -m http.server 8000` (потрібен установлений Python).
5. Відкрийте `http://localhost:8000/` у браузері.
6. Натисніть «Почати навчання» або «Відкрити лабораторію».

Якщо Python не встановлено, можна використовувати VS Code з розширенням Live Server або опублікувати сайт на GitHub Pages.

## GitHub Pages

Завантажте **вміст** папки `devmate-academy` до кореня репозиторію та ввімкніть Settings → Pages → Deploy from a branch → main / (root). У Moodle розміщуйте пряме посилання на `.../lessons/lesson-01/index.html`.

## Що реалізовано
- Адаптивна головна сторінка Editorial Study × Soft Digital.
- Каталог усіх 14 лабораторій; LAB 01 активна, LAB 02–14 позначені «Незабаром» (не видаються за готові).
- LAB 01: п'ять етапів, теорія, контракт, приклади, коротке пояснення async, редактор JavaScript, п'ять автоматизованих тестів, власний тест, збереження чернетки у localStorage, завантаження JS та TXT-звіту.
- Учнівський код запускається у Web Worker з тайм-аутом 2 секунди. Це ізоляція від DOM основної сторінки, **не повноцінна пісочниця безпеки для ворожого коду**. Не вставляйте секрети в сайт. Для широкого публічного використання потрібен додатковий аудит.

## Запуск локально
Worker зазвичай не працює при відкритті HTML через `file://`. Запустіть локальний HTTP-сервер:

```bash
cd devmate-academy
python -m http.server 8000
```

Відкрийте http://localhost:8000/ .

## GitHub Pages
1. Створіть **публічний** репозиторій, наприклад `devmate-academy`.
2. Завантажте **вміст цієї папки** в корінь репозиторію (щоб `index.html` був у корені).
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Адреса зазвичай має вигляд `https://USERNAME.github.io/devmate-academy/`.
5. У Moodle додайте ресурс «URL» на сторінку `.../lessons/lesson-01/`, а поруч — елемент «Завдання» для здавання файлів.

## Обмеження
- Жодної автоматичної передачі результатів або оцінок до Moodle.
- Чернетка зберігається лише в конкретному браузері та може зникнути при очищенні даних.
- `async` у LAB 01 пояснюється лише ознайомчо; тести синхронні, бо сама функція синхронна.
- Для обчислень з грошима у промислових системах потрібні окремі правила точності й округлення.
- Не виконуйте в цьому тренажері невідомий шкідливий код; це навчальний інструмент, а не захищена онлайн-пісочниця.
