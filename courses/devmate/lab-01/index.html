01 / Досліджуємо

Код виглядає правильним. А результат?

Уявіть: ШІ створив функцію для кошика інтернет-магазину. Ціна одного товару — 100 грн, кількість — 2, знижка — 10%.

function calculateTotal(price, quantity, discount) {
  return price * quantity - discount;
}

Поміркуйте: чому функція повертає 190 замість 180? Чи може неправильна формула випадково пройти окремий тест?

Перш ніж виправляти код, сформулюйте очікувану поведінку. Код, що запускається без помилок, не обов'язково виконує завдання правильно.
02 / Уточнюємо вимоги

Контракт функції

Контракт — домовленість про допустимі аргументи, очікуваний результат і поведінку в разі некоректних даних.

  • price: скінченне число ≥ 0;
  • quantity: ціле невід'ємне число;
  • discount: скінченне число від 0 до 100;
  • результат: сума після відсоткової знижки;
  • помилкові дані: генерувати виняток.
total = price × quantity × (1 − discount / 100)

Ціла кількість — умова саме цієї вправи. У реальних продажах товарів на вагу дробова кількість може бути допустимою.

03 / Розбираємо JavaScript

Перевіряємо дані

Number.isFinite(value) повертає true лише для скінченного значення типу number. Number.isInteger(value) перевіряє цілочисельність, але не забороняє від'ємні числа.

Number.isFinite(100);      // true
Number.isFinite('100');    // false
Number.isFinite(Infinity); // false
Number.isInteger(1.5);    // false
Number.isInteger(-3);     // true

Оператор === порівнює значення без перетворення типів. throw new RangeError(...) створює виняток для недопустимого значення.

Знайомство з async: async () => ... — асинхронна стрілкова функція. Вона завжди повертає Promise. У нашій вправі асинхронність не потрібна для обчислення, але може використовуватися тестовою системою. await дозволяє отримати результат Promise всередині асинхронної функції. Самостійно писати async сьогодні не обов'язково.

Питання: чому перевірки Number.isInteger(quantity) недостатньо? Що станеться при quantity = -3?

Джерела: MDN isFinite · MDN isInteger · MDN async

04 / Практика

П'ять тестів + власний

Виправте функцію у редакторі праворуч. Запустіть перевірку. Для помилкових аргументів функція повинна генерувати виняток.

  1. Звичайна знижка: (100, 2, 10) → 180
  2. Нульова кількість: (100, 0, 10) → 0
  3. Знижка 100%: (100, 1, 100) → 0
  4. Недопустима знижка: (100, 1, 101) → виняток
  5. Дробова кількість: (100, 1.5, 10) → виняток
Підказка: використайте Number.isFinite(), Number.isInteger() та перевірки меж. Не підмінюйте тести: потрібно виправити саму функцію.

Власний тест має перевіряти новий випадок, а не повторювати базові приклади.

05 / Результат

Захист і здавання роботи

Завантажте свій файл calculateTotal.js кнопкою праворуч. До Moodle надішліть його разом із коротким звітом (5–7 речень) та власним тестом.

Критерії — 12 балів

  • Аналіз початкової помилки — 2
  • Правильність обчислення — 2
  • Перевірка аргументів — 3
  • Базові тести й аналіз — 2
  • Власний тест — 2
  • Пояснення рішення — 1

Оцінку виставляє вчитель у Moodle. PASS / FAIL на сайті — інструмент самоперевірки, а не автоматична оцінка.
